QR Code Generator

SVG output with optional center logo — fully driven by URL query parameters

Query parameters: data (text to encode), logo (logo image URL), size, fg, bg, ec (L/M/Q/H), logoSize (0-30%), download=1 (auto-download), fmt (svg | png, default svg).
Example: qrcode.html?data=https://example.com&logo=https://example.com/logo.png&fg=%23000000&fmt=png
Works with no params (defaults to SVG). If the logo server allows CORS, it's embedded in the SVG; otherwise it's referenced by URL (still renders/downloads, but stays a live link).
